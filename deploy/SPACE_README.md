# BasinPulse (BASINSHIFT entry)

BasinPulse forecasts river flow 1, 3 and 7 days ahead, with a 10–90% range and probabilities of high and extreme
flow, on rivers it has never seen. This site shows the results logged on the BASINSHIFT test set (60 unseen
CAMELS-US rivers, 2008–2014) and runs the submitted model live on a CSV you upload ("Try the model").

- Code, report, model card and reproduction guide: https://github.com/10sumitsingh01-collab/floodcast-basinpulse
- Data: Caravan v1.6 / CAMELS-US (CC-BY-4.0), LaMAH-CE (CC-BY-SA). Real observations only.

Research benchmark entry. Not a flood-warning service: never the sole basis for evacuation, emergency response,
infrastructure operation or public warnings.

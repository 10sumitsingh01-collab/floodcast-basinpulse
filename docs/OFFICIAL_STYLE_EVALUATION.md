## 5. Section 10.2 machine score (our pre-declared normalization)

The specification gives the weights but says the normalization must still be frozen (10.3), so the official number can only be computed by the organizers. We fixed our own formula in `scripts/official_eval.py` before reading any result: every skill term is 0 at persistence level and full marks only for a perfect forecast, so this is a strict scale; persistence is scored with the same formula for reference.

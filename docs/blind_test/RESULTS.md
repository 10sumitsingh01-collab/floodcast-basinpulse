# Blind test of the live prototype on unseen rivers

Generated by `scripts/blind_test.py` against https://basinpulse.onrender.com (2026-11-05 06:43 UTC).

- **Rivers:** the 3 Central European rivers (LaMAH-CE) with the most severe June 2013 flood relative to their own extreme-flow line, chosen by flood severity before any forecast was made. The submitted model was trained on US rivers only, so these rivers, this country and this flood were never seen.
- **What the website got:** `inputs.csv`: measured flow so far and weather, 2008-10 to 2013-12. No answers. Uploaded to `/api/forecast` exactly like *Drop a CSV*.
- **Website:** 5,754 forecast days in 40 s; output passes the BASINSHIFT format checks.
- **Answer key:** `answers.csv`, the real flow 1, 3 and 7 days after each day of 2013, compared only afterwards. Persistence = "the flow stays as it is today".

# Validation experiments (training data only)

Every model choice was made from these tables. The test set was scored once, with the final model.
Validation: `val_unseen_basins` = station folds 0 and 1 of `splits.json` (96 training basins held out,
model fitted on the other 143); `val_temporal` = all 239 training basins, fit to 2006-09, validate
2006-10 to 2008-09 (persistence and LightGBM use the same splits). Generated by
`scripts/summarize_validation.py`.

## Experiments

| run | what it tests |
|---|---|
| Persistence (`val_persistence`) | reference: tomorrow = today, calibrated range and probabilities |
| LightGBM v1 (median) (`val_lgbm_v1`) | quantile LightGBM, median as forecast |
| LightGBM v2 (mean) (`val_lgbm_v2_mean`) | v1 + mean forecast with Duan smearing |
| H1: no catchment attributes (`val_h1_nostatic`) | v1 without the 28 static attributes |
| No flow history (ungauged) (`val_noflow`) | v1 without any observed-flow input |
| H4: robustness training (`val_robust_h4`) | v1 trained with 15% of inputs hidden |
| Final: H4 + mean (`val_robust_mean`) | robustness training + mean forecast |

## Decisions

1. **LightGBM over persistence:** better on every horizon for NSE, MAE, AUPRC, Brier skill, with calibrated and narrower ranges at 3 and 7 days.
2. **Mean forecast (v2) over median (v1):** higher NSE and KGE at every horizon; MAE slightly higher (expected: the median minimises absolute error). NSE is the primary skill metric.
3. **H1 (catchment attributes):** small, consistent gains in most metrics, within the confidence intervals. Kept. Most transfer comes from predicting change relative to the basin's own flow.
4. **H4 (robustness training):** rule fixed before looking: adopt if mean stressed 1-day NSE improves by >= 0.01 and clean unseen-basin NSE drops by < 0.02. Result: +0.025 and -0.011, so adopted.
5. **Final combination (H4 + mean):** kept if its unseen-basin 1-day NSE is within 0.02 of v2.
6. **No flow history:** not a candidate; reported as the ungauged-basin case.
